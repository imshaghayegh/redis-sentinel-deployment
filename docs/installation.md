# Redis Sentinel Installation Guide

## Overview

This document describes the installation and configuration procedure
for Redis and Redis Sentinel using the official Redis binary package.

## Architecture

Redis Sentinel provides:
- High Availability
- Automatic Failover
- Master monitoring
- Replica promotion

# Prerequisites

Minimum requirements:

- Linux server
- CPU: 2 Core
- RAM: 4 GB
- Network connectivity between Redis nodes

Required ports:

| Service | Port |
|---|---|
| Redis | 6379 |
| Sentinel | 26379 |

# Installation

## Download Redis Package

Download Redis binary package:

```bash
wget https://download.redis.io/releases/redis-8.0.5.orig.tar.gz
```
# Redis Sentinel Installation Guide

## 1. Extract Redis Package

Extract Redis source package:

```bash
tar xvzf redis-8.0.5.orig.tar.gz
```

Go to Redis directory:

```bash
cd redis-8.0.5
```

---

# 2. Compile Redis

Build Redis from source:

```bash
make
```

Run Redis test suite:

```bash
make test
```

Install Redis binaries:

```bash
make install
```

Verify Redis installation:

```bash
redis-server --version
```

Expected output:

```
Redis server v=8.0.5
```

Installed binaries:

```
redis-server
redis-cli
redis-sentinel
```

---

# 3. Create Redis User

Create dedicated system user:

```bash
useradd --system \
--no-create-home \
--shell /usr/sbin/nologin \
redis
```

Verify user:

```bash
id redis
```

---

# 4. Create Redis Directories

Create required directories:

```bash
mkdir -p /etc/redis

mkdir -p /var/lib/redis

mkdir -p /var/log/redis

mkdir -p /var/lib/sentinel

mkdir -p /var/log/sentinel

```

Directory structure:

```
/etc/redis
    ├── redis.conf
    └── sentinel.conf

/var/lib/redis
    └── Redis data files

/var/log/redis
    └── Redis logs

/var/lib/sentinel
    └── sentinel data files

/var/log/sentinel
    └── sentinel logs
```

---

# 5. Set Permissions

Change ownership:

```bash
chown -R redis:redis /var/lib/redis

chown -R redis:redis /var/log/redis

chown -R redis:redis /var/lib/sentinel

chown -R redis:redis /var/log/sentinel

chown -R redis:redis /etc/redis
```

---

# 6. Create Redis Configuration Files

Create Redis configuration file:

```bash
touch /etc/redis/redis.conf
```

Set permission:

```bash
chmod 750 /etc/redis/redis.conf
```

Create Sentinel configuration file:

```bash
touch /etc/redis/sentinel.conf
```

Set permission:

```bash
chmod 640 /etc/redis/sentinel.conf
```

---

# 7. Configure Redis

Edit Redis configuration:

```bash
touch /etc/redis/redis.conf
```

Example configuration:

```conf
bind 0.0.0.0
protected-mode no
port 6379
supervised systemd
daemonize no
pidfile "/var/run/redis/redis-server.pid"
logfile "/var/log/redis/redis.log"
dir "/var/lib/redis"
# Authentication
requirepass "123456"
masterauth "123456"

# Save settings
save 900 1
save 300 10
save 60 10000
dbfilename "dump.rdb"

# Optional performance settings
tcp-backlog 511
tcp-keepalive 300
loglevel notice
rdbcompression yes
rdbchecksum yes
always-show-logo yes

# Generated by CONFIG REWRITE
latency-tracking-info-percentiles 50 99 99.9
user default on sanitize-payload 

### Add this line in replica servers ###
replicaof <REDIS_MASTER_IP> 6379
```

---

# 8. Configure Redis Sentinel

Edit Sentinel configuration:

```bash
vi /etc/redis/sentinel.conf
```

Example:

```conf
port 26379

daemonize no

sentinel monitor mymaster <REDIS_MASTER_IP> 6379 2

sentinel down-after-milliseconds mymaster 5000

sentinel failover-timeout mymaster 60000

sentinel parallel-syncs mymaster 1
```

Replace:

```
<REDIS_MASTER_IP>
```

with Redis master IP address.

---

# 9. Create Redis Systemd Service

Create Redis service file:

```bash
vi /etc/systemd/system/redis.service
```

Content:

```ini
[Unit]
Description=Redis Server
After=network.target

[Service]

User=redis
Group=redis

ExecStart=/usr/local/bin/redis-server /etc/redis/redis.conf

ExecStop=/usr/local/bin/redis-cli shutdown

Restart=always

LimitNOFILE=10032

[Install]

WantedBy=multi-user.target
```

---

# 10. Create Sentinel Systemd Service

Create Sentinel service file:

```bash
vi /etc/systemd/system/sentinel.service
```

Content:

```ini
[Unit]
Description=Redis Sentinel
After=network.target redis.service

[Service]

User=redis
Group=redis

ExecStart=/usr/local/bin/redis-sentinel /etc/redis/sentinel.conf

Restart=always

[Install]

WantedBy=multi-user.target
```

---

# 11. Reload Systemd

Reload systemd configuration:

```bash
systemctl daemon-reload
```

---

# 12. Enable Redis and Sentinel Services

Enable Redis service:

```bash
systemctl enable redis
```

Enable Sentinel service:

```bash
systemctl enable sentinel
```

---
# 13. Start Redis and Sentinel Services

Start Redis:

```bash
systemctl start redis
```

Start Sentinel:

```bash
systemctl start sentinel
```

---

# 14. Verify Redis Service

Check Redis status:

```bash
systemctl status redis
```

Check Redis process:

```bash
ps -ef | grep redis
```

---

# 15. Verify Sentinel Node ID

Each Sentinel instance has a unique identifier (Sentinel ID).

After starting the Sentinel service, retrieve the Sentinel ID using:

```bash
redis-cli -p 26379 SENTINEL MYID
```
Example output:
98160b0bf3a9ce9f4208e23c87f2d6a9b0cc29b9

You should put this ID in sentinel.conf (refer to sentinel.conf)

---


# 16. Test Redis Connection

Connect to Redis:

```bash
redis-cli
```

Run:

```bash
PING
```

Expected response:

```
PONG
```

---

# 17. Verify Sentinel Service

Check Sentinel status:

```bash
systemctl status sentinel
```

Check Sentinel master information:

```bash
redis-cli -p 26379 SENTINEL masters
```

---

# 18. Get Current Redis Master

Find current master:

```bash
redis-cli \
-p 26379 \
SENTINEL get-master-addr-by-name mymaster
```

Example output:

```
1) "10.10.10.10"
2) "6379"
```
